# ADR-0013: Proprietary license notice in every application repository

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** Amends DEC-011; implements prompt section 3

## Context

The Phase 0 setup prompt requires a proprietary 'all rights reserved' notice for the private product in every app repo, while governance docs remain MIT (DEC-001/DEC-011).

## Decision

TDOP-backend, TDOP-frontend, TDOP-infra, TDOP-mobile each carry a proprietary LICENSE (all rights reserved); TDOP-docs keeps the MIT license for governance content.

## Consequences

Product code is closed; open governance docs remain shareable; DEC-011 scope narrowed to the docs repo.

# ADR-0004: Existing code never auto-credits phase completion

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-004

## Context

Pre-existing repository code was not verified against phase exit criteria (DEC-004).

## Decision

Inventory existing code in EXISTING_IMPLEMENTATION_AUDIT.md; phases start at 0% regardless of code that exists; only verified work completes a phase.

## Consequences

The tracker cannot be falsified by unverified code; the audit drives future verification tasks.

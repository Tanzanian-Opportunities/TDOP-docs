# ADR-0002: The 33-phase roadmap is the authoritative project progression

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-002; coexists with the 0-10 business phases in docs/business/roadmap.md

## Context

Governance needs one fixed phase sequence; older 7-phase outlines in the repository were product-planning sketches with different names (DEC-002).

## Decision

Adopt the 33-phase sequence (PHASE 01 - Project Initiation ... PHASE 33 - Continuous Improvement) in PROJECT_MANAGEMENT.md section 5 as the only authoritative progression; older outlines remain historical sketches.

## Consequences

All tracking follows one sequence; TASK_BREAKDOWN (177 tasks) and the Kanban mirror it.

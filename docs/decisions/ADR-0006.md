# ADR-0006: Repository ownership moves to the Tanzanian-Opportunities organization

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-006

## Context

The owner created the GitHub organization and wanted the project owned by it rather than a personal account (DEC-006).

## Decision

Transfer the repository to the organization (name unchanged at the time); documentation URLs updated.

## Consequences

Clone/advisory/documentation URLs point at the organization; ownership is institutional.

# ADR-0005: Technology stack of record

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-005; extended by ADR-0010 (mobile) and ADR-0009 (edge topology)

## Context

Development standards and environment setup need a declared stack that matches what is actually present (DEC-005).

## Decision

Backend: Java 21 / Spring Boot 3.3 / PostgreSQL / Flyway. Frontend: React 18 / TypeScript / Vite / Tailwind. Infra: Docker Compose / Nginx / Cloudflare. Recorded in READMEs and docs/planned-technologies.md.

## Consequences

Standards, hiring/training expectations, and CI match the stack; re-platforming would be a new decision.

# ADR-0014: Repositories stay public; branch protection enabled on develop (free tier)

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** Owner decision; prompt section 1

## Context

The prompt says private repos (branch protection then needs a paid plan), but the owner chose to keep all five repositories public and use the free branch protection that public repos get (owner decision, recorded 2026-09-30).

## Decision

Keep TDOP-* repositories public; enable branch protection on develop in every repo (PR required, CI status check required, administrators not enforced so scripted pushes keep working); document the paid-plan limitation for private repos in DEVELOPMENT_GUIDE.

## Consequences

Free protection is active; the private-repo/paid-plan limitation is documented as required by the prompt; visibility can still be changed later (new decision would follow).

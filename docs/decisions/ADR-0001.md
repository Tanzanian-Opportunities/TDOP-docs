# ADR-0001: License TDOP under the MIT License

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-001; amended by ADR-0011, scoped further by ADR-0013

## Context

The owner declared 'License: MIT' in the repository README, but no LICENSE file existed to back the declaration (DEC-001).

## Decision

Add an explicit MIT LICENSE file to TDOP-docs, with the copyright holder recorded from commit history (amendable by the owner).

## Consequences

The repository carries an explicit license; forks/redistribution terms are clear.

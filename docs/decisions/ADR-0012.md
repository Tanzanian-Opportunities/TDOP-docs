# ADR-0012: Dissolve the umbrella index repository

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-012; supersedes umbrella part of DEC-007

## Context

The owner wanted fewer repositories to keep consistent; overview/index duties belong to the source-of-truth repo (DEC-012).

## Decision

Move the umbrella's important content to TDOP-docs/PROJECT_OVERVIEW.md, archive a git bundle, delete the Tanzanian_Opportunities repository (GitHub + local); supersedes the umbrella part of ADR-0007.

## Consequences

Five repositories remain; full monorepo history kept in a session-storage bundle.

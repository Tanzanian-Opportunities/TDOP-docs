# ADR-0011: Single license of record lives only in TDOP-docs

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-011; amended by ADR-0013

## Context

Five drifting LICENSE copies were a maintenance risk (DEC-011).

## Decision

The MIT LICENSE file lives only in TDOP-docs; component repositories link to it instead of carrying a copy.

## Consequences

One canonical license file; READMEs declare and link it.

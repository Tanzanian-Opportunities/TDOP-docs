# ADR-0007: Split the monorepo into component repositories with an org Kanban board

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-007; umbrella part superseded by ADR-0012

## Context

Clearer ownership per component and preserved history were requested by the owner (DEC-007).

## Decision

Create TDOP-backend, TDOP-frontend, TDOP-infra, TDOP-docs, TDOP-mobile with main + develop branches each; mirror all 177 tasks as cards on the organization GitHub Projects board.

## Consequences

History was subtree-split per component; the umbrella part of this decision was later superseded by ADR-0012.

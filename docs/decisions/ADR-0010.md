# ADR-0010: Mobile application stack: Flutter / Dart

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-010

## Context

Owner directive after stack review; cross-device coverage without two native codebases (DEC-010).

## Decision

TDOP-mobile is Flutter/Dart targeting Android and iOS from one codebase; CI runs analyze/test once pubspec.yaml exists.

## Consequences

One mobile codebase; Dart tooling joins the stack (see planned-technologies).

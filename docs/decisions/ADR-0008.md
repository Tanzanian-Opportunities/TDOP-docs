# ADR-0008: Phase lifecycle vocabulary is independent of task states

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-008

## Context

Phase states describe whole-phase position and must not be confusable with task columns (DEC-008).

## Decision

Phases use Planned / In progress / Completed everywhere (roadmaps, trackers, CHANGELOG wording uses 'Completed' for finished phases).

## Consequences

Two clear vocabularies: phases vs tasks; validators enforce both.

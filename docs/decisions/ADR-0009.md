# ADR-0009: Production edge topology: Cloudflare front, Nginx origin proxy in backend

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-009

## Context

Owner directive on where the reverse proxy belongs (DEC-009).

## Decision

Cloudflare fronts production (DNS, TLS, CDN, WAF); the Nginx origin proxy lives in TDOP-backend/nginx.conf, not TDOP-infra; TDOP-infra stays Compose/environment orchestration plus edge config references.

## Consequences

Clear service boundaries; backend owns its proxy config.

# ADR-0003: Six-state Kanban is the only permitted task state set

- **Status:** Accepted
- **Date:** 2026-09-30
- **Related:** DEC-003

## Context

Free-form statuses make project position ambiguous (DEC-003).

## Decision

Tasks may only be BACKLOG, TO DO, IN PROGRESS, CODE REVIEW, TESTING, or DONE - on every board, session, and definition (DoR/DoD).

## Consequences

Position is readable at a glance; the docs validator enforces the vocabulary.
